MyAcademy Laravel - MySQL Connection Fix
========================================

The 500 server error is caused by MySQL connection issues. Here's how to fix it:

SOLUTION 1: Reset MySQL Root Password in Laragon
------------------------------------------------
1. Open Laragon Control Panel
2. Right-click on "MySQL" service
3. Select "Root Password" or "Change Password"
4. Set password to empty or "root"
5. Restart MySQL service

SOLUTION 2: Use HeidiSQL to Create Database Manually
---------------------------------------------------
1. Open Laragon Control Panel
2. Click "Database" button (opens HeidiSQL)
3. Try connecting with:
   - Host: 127.0.0.1
   - User: root
   - Password: (try empty, "root", or check Laragon settings)
4. Once connected, run these SQL commands:

   CREATE DATABASE IF NOT EXISTS myacademy;
   CREATE USER IF NOT EXISTS 'myacademy'@'localhost' IDENTIFIED BY 'Myacademy@2026!';
   GRANT ALL PRIVILEGES ON myacademy.* TO 'myacademy'@'localhost';
   FLUSH PRIVILEGES;

5. Update .env file with working credentials

SOLUTION 3: Reinstall MySQL in Laragon
--------------------------------------
1. Stop all services in Laragon
2. Go to Laragon > Menu > MySQL > Version
3. Switch to a different MySQL version, then back
4. This will reset MySQL with default settings

SOLUTION 4: Manual MySQL Configuration
--------------------------------------
1. Find your Laragon MySQL installation folder (usually C:\laragon\bin\mysql\)
2. Look for my.ini or my.cnf file
3. Add these lines under [mysqld]:
   skip-grant-tables
4. Restart MySQL
5. Connect without password and reset root password:
   ALTER USER 'root'@'localhost' IDENTIFIED BY '';
6. Remove skip-grant-tables and restart

SOLUTION 5: Use Different Database
----------------------------------
If MySQL continues to have issues, you can temporarily use SQLite:

1. Change .env file:
   DB_CONNECTION=sqlite
   DB_DATABASE=C:\laragon\www\myacademy-laravel\database\database.sqlite

2. Create empty SQLite file:
   touch database/database.sqlite

3. Run migrations:
   php artisan migrate --force
   php artisan db:seed --force

AFTER FIXING DATABASE CONNECTION:
=================================
1. Clear Laravel caches:
   php artisan config:clear
   php artisan cache:clear
   php artisan view:clear

2. Run migrations:
   php artisan migrate --force

3. Seed database:
   php artisan db:seed --force

4. Start the application:
   php artisan serve --host=0.0.0.0 --port=8000

5. Access at: http://localhost:8000
